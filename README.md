# Pantry — Recipe Finder

A simple, responsive recipe finder web app. Search any dish or ingredient and get a full recipe with ingredients and cooking instructions, pulled live from [TheMealDB](https://www.themealdb.com/api.php) free API.

## Features

- 🔍 Search recipes by name or ingredient
- 🍳 Quick-search chips (Chicken, Pasta, Rice, Curry, Dessert, Soup)
- 📖 Full recipe modal with ingredients list and step-by-step method
- 📱 Fully responsive — works on mobile, tablet, and desktop
- ⚡ No backend or API key required

## Tech Stack

- HTML5
- CSS3 (custom, no framework)
- Vanilla JavaScript (fetch API)
- [TheMealDB API](https://www.themealdb.com/api.php)

## Getting Started

1. Clone the repo:
   ```bash
   git clone https://github.com/Haniabatool72/recipe-finder.git
   ```


## Deploy on GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings → Pages**.
3. Under **Source**, select the `main` branch and `/root` folder.
4. Save — your app will be live at `https://your-username.github.io/recipe-finder/`.
